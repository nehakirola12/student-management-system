# student-management-system
The Student Management System is a Python-based application designed to manage student records efficiently. It allows users to add, view, search, and delete student information such as student ID, name, and marks. The project uses Object-Oriented Programming (OOP) concepts, including classes and objects, to organize and manage data. 

====> Features
1.Add new student records
2.View all students
3.Search students by ID
4.Delete student records
5.Easy-to-use command-line interface

===>Learning Outcomes
* Understanding OOP concepts in Python
* Working with data structures
* Building menu-driven applications
* Managing and organizing data efficiently
